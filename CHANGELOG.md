# Дельта — что изменилось с прошлой полной сборки

Это не весь сайт, а только файлы, которые поменялись или добавились в этом раунде правок.
Разложите по тем же путям в своём проекте (перезапишите существующие файлы этими).

## Новые файлы
- `components/TourGallery.tsx` — галерея фото тура с лайтбоксом (клик → полноэкранный просмотр, стрелки, Esc).
- `public/img/icons/icon-nature.webp`, `icon-route.webp`, `icon-water.webp` — нарезанные значки (горы+берег / маршрут+метка / волны+чайки), применены на страницах категорий.

## Изменённые файлы и что в них поменялось

**`content/site.json`**
- Тексты и структура 5 экскурсий (irkutsk, listvyanka, teplokhod, baykalsk, arshan) переписаны на основе старого сайта: у каждой теперь `program` — пронумерованные остановки маршрута с таймингом, вместо одного абзаца.
- Мелкая правка `difficulty` у baykalsk (упоминание клещей летом).
- Hero-картинка главной **не менялась** — осталась исходная (оставляю здесь для ясности, чтобы не перепутать при мердже).

**`app/[region]/tury/[slug]/page.tsx`**
- Статичный блок фото+миниатюры заменён на `<TourGallery>` (клик по фото открывает лайтбокс).
- Заголовок блока программы теперь `«Маршрут экскурсии»` для однодневных экскурсий и `«Программа по дням»` для многодневных туров.

**`app/baikal/[category]/page.tsx`**
- Добавлена карта `CATEGORY_ICONS` и рендер иконки-бейджа над `<h1>` для категорий `individualnye`, `iz-moskvy`, `iz-spb` (иконка маршрута), `kruizy` (волны), `ekskursii` (природа).

**`app/napravleniya/page.tsx`**
- Иконка природы над заголовком «Другие направления».

**`app/page.tsx`, `app/en/page.tsx`**
- Оверлей на hero усилен: теперь два слоя (вертикальный + горизонтальный слева, где текст) вместо одного — текст читается на любом участке фото.
- Кнопка «Подобрать тур» / «...» на hero: была почти прозрачная, стала непрозрачной белой (`btn-frost`).

**`app/layout.tsx`, `tailwind.config.ts`, `app/globals.css`**
- Шрифт заголовков сменён с Playfair Display на Montserrat (жирный).
- В палитру добавлен `dawn-600` (тёмное золото для hover).
- Добавлен класс `.btn-frost` (непрозрачная белая кнопка на тёмном фоне).

**`components/Logo.tsx`**
- Текстовый логотип заменён на настоящий файл `public/img/logo.png` (уже был у вас в первой сборке — здесь просто компонент, который его выводит).

**`components/DepartureStrip.tsx`** (панель «Ближайшие заезды»)
- Скругление углов увеличено (`rounded-3xl` вместо почти прямых углов).
- Название тура — золотым цветом (`dawn-500`), чтобы было явно видно, что оно кликабельно.

**`components/TourRow.tsx`, `components/EnTourRow.tsx`**
- Фото в строке тура увеличено (было 220px, стало 320px по ширине).

**`package.json`**
- Добавлена зависимость `@fontsource-variable/montserrat`.
- Убрана неиспользуемая `@fontsource/playfair-display`.
- После замены файла выполните `npm install`.

**`README.md`**
- Обновлено упоминание шрифта (Montserrat вместо Playfair) и логотипа.

## Что нужно сделать после мерджа
```
npm install
npm run build
```
