# Правка: кнопка «Летние туры 2027» + инструкция для заказчика

Два файла, оба новые или изменённые только сейчас. Всё остальное уже в репозитории — проверил сверкой с GitHub.

## Что в архиве

**`app/page.tsx`** — на первом экране главной добавлена вторая кнопка. Теперь там три: «Зимние туры 2027», «Летние туры 2027» и «Подобрать тур».

Сделано с учётом переключателя сезона: первой всегда идёт кнопка текущего сезона (золотая), второй — противоположного (белая). Переключите `season` на `summer` — и кнопки поменяются местами сами, править ничего не придётся.

**`KAK-PRAVIT-SAYT.md`** — инструкция для заказчика: как заливать правки через GitHub, как менять сезон, цены, даты заездов, тексты туров, как добавлять фотографии, туры и статьи в блог. Отдельно расписано, чего лучше не трогать и что делать, если правка что-то сломала.

Файл кладётся в корень репозитория, рядом с `README.md` — его будет видно на главной странице репозитория в списке файлов.

## Как залить

Add file → Upload files → перетащить оба файла (`KAK-PRAVIT-SAYT.md` в корень, `app/page.tsx` в папку `app`) → Commit changes.
