# Срочная правка: счётчик Метрики и ошибка формы

## Что было сломано

**1. Метрики не было на сайте.** Компонент использовал `next/script`, тег попадал в Suspense-границу и в HTML не выводился — в страницу уходила только картинка-заглушка для браузеров без JavaScript. Проверка `?_ym_debug=2` счётчик не находила.

**2. Форма писала «Не отправилось», хотя заявка приходила в Telegram.** После успешной отправки вызывалась цель Метрики, `window.ym` не существовал, ошибка попадала в тот же обработчик, что и отправка, и форма краснела.

## Что исправлено

- `components/Metrika.tsx` — обычный `<script>` вместо `next/script`. Счётчик теперь на всех страницах.
- `lib/ym.ts` — функция отправки целей больше не бросает исключений никогда: ни при блокировщике рекламы, ни в приватном режиме, ни если счётчик не успел загрузиться.
- `components/LeadForm.tsx` — вызовы целей вынесены за пределы обработчика отправки. Аналитика физически не может повлиять на то, что видит человек.

## Как залить

Три файла по тем же путям, коммит, Vercel пересоберётся сам. Новых зависимостей нет.

## Как проверить

1. Открыть сайт с хвостом `?_ym_debug=2`, в консоли браузера должны появиться сообщения Метрики
2. В Метрике → Отчёты → По времени суток посмотреть, что визиты пошли
3. Отправить тестовую заявку: в Telegram приходит сообщение, форма показывает зелёное «Спасибо», красной надписи нет
4. В Метрике → Отчёты → Конверсии через несколько минут появится цель `lead_submit`
