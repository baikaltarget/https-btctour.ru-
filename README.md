# Правка: не стиралось поле телефона

## Что было

Маска возвращала разделители обратно. Стираешь закрывающую скобку в «+7 (983)» — маска тут же дописывает её снова, и поле дальше не стирается. Очистить номер было невозможно.

## Что исправлено

`lib/phone.ts` — функция форматирования теперь знает предыдущее значение поля и понимает, что идёт удаление. Если стёрли разделитель (скобку, пробел, дефис), снимается ещё и цифра перед ним — иначе значение не изменилось бы вовсе.

`components/LeadForm.tsx` — в маску передаётся текущее значение поля.

Проверено: номер стирается по одному символу до полной очистки, ввод и вставка номера работают как раньше.
