# btctour.ru — сайт туроператора «Байкал Трэвэл Компани»

Next.js 15 (App Router) + Tailwind, статическая генерация, хостинг GitHub → Vercel. 103 страницы, JSON-LD, sitemap, 85 редиректов со старого Tilda-сайта, формы в Telegram.

## 1. Как опубликовать (10 минут)

1. GitHub → **New repository** (private) → на странице пустого репо нажать **uploading an existing file** → перетащить **содержимое** этой папки (в корне должен лежать `package.json`) → Commit.
2. vercel.com → **Add New → Project → Import** этот репозиторий → ничего не менять → **Deploy**. Через 2–3 минуты сайт на `https://<имя>.vercel.app`.
3. Проверить глазами и с телефона (нижняя панель: кнопка «Позвонить» открывает набор).
4. Домен: Vercel → Project → Settings → Domains → `btctour.ru` → прописать у регистратора A-запись `76.76.21.21` и CNAME `www` → `cname.vercel-dns.com`. **Только после проверки на vercel.app.** Tilda до этого момента не отключать.
5. Telegram-бот для заявок: создать бота в @BotFather, узнать chat_id (добавить бота в группу, написать в неё, открыть `https://api.telegram.org/bot<TOKEN>/getUpdates`). В Vercel → Settings → Environment Variables добавить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` → Redeploy. Пока ключей нет, заявки видны в Vercel → Functions → Logs и не теряются.

Если после правки на GitHub сайт не обновился: счётчик коммитов на GitHub → Vercel → Deployments (Building / Ready / Error) → Ctrl+Shift+R.

## 2. Где что править (заказчик правит только `content/`)

| Что | Где |
|---|---|
| Телефоны, почта, адрес, часы, реквизиты | `content/site.json` → `site` |
| **Сезон главной** (`winter` / `summer`) — меняет герой, порядок туров и панель заездов | `content/site.json` → `season` |
| Красные рамки «проверить» (выключить перед публикацией) | `content/site.json` → `dev.showTodos: false` |
| Туры Байкала: цены, даты, места, программа | `content/site.json` → `tours[]` |
| Категории (H1, title, description, FAQ, тексты) | `content/site.json` → `categories[]` |
| Камчатка, Алтай, Владивосток, Краснодар | `content/site.json` → `regions[]` |
| Отзывы, общий FAQ, меню, футер | `content/site.json` → `reviews`, `faqGeneral`, `nav`, `footerLinks` |
| Английская версия | `content/site.en.json` |
| Статьи блога | `content/blog/*.md` (заголовок в шапке файла) |
| Фото | `public/img/` — заливать сразу сюда: `github.com/<user>/<repo>/upload/main/public/img` |
| Дизайн (цвета, шрифты) | `tailwind.config.ts`, `app/globals.css` |

**Даты заездов.** В каждом туре массив `departures`: `{ "from": "2027-02-15", "to": "2027-02-19", "seats": 8, "total": 8 }`. Уменьшили `seats` — на сайте сразу «свободно 5 из 8». Прошедшие даты скрываются сами. Панель «Ближайшие заезды» на главной строится из этих данных.

**Добавить тур.** Скопировать любой объект в `tours[]`, поменять `slug` (латиница, это адрес `/baikal/tury/<slug>/`), тексты, цену, даты. Страница, sitemap, панель заездов и категории подхватят сами по полям `season`, `tags`, `locations`, `type`.

**Добавить фото туру.** Положить `public/img/tours/<slug>.webp` (ширина 1600, через squoosh.app → WebP) и добавить в тур `"image": "/img/tours/<slug>.webp"`. Пока поля нет — рисуется ледяной паттерн.

**Новогодний тур.** Когда будет программа — новый объект в `tours[]` с `"tags": ["newyear","ice"]`, он автоматически попадёт на `/baikal/novyy-god/`.

## 3. Структура адресов

- `/` — главная (Байкал, сезонная)
- `/baikal/` — все туры; `/baikal/zimnie/`, `/letnie/`, `/novyy-god/`, `/led/`, `/kruizy/`, `/ekskursii/`, `/olkhon/`, `/kbzhd/`, `/listvyanka/`, `/arshan/`, `/vertoletnye/`, `/iz-irkutska/`, `/iz-moskvy/`, `/iz-spb/`, `/individualnye/`
- `/baikal/tury/<slug>/` — карточки туров и экскурсий (22)
- `/napravleniya/` → `/kamchatka/`, `/altay/`, `/vladivostok/`, `/krasnodarskiy-kray/` + `/<регион>/tury/<slug>/` (черновики в noindex)
- `/o-kompanii/`, `/kontakty/`, `/agentam/`, `/corporate/`, `/world/`, `/blog/`, `/blog/<slug>/`
- `/tury/` (поиск, noindex), `/oplata/`, `/politika/` (noindex)
- `/en/`, `/en/baikal/`, `/en/baikal/tury/<slug>/`, `/en/contacts/` — hreflang прописан
- `/sitemap.xml`, `/robots.txt` — автоматически; `vercel.json` — 301 со всех старых адресов Tilda

## 4. Что уточнить у заказчика (все места обведены красной рамкой на сайте)

1. Адрес офиса и точка на карте (контакты, футер).
2. Новогодняя программа 30.12–03.01 (сейчас на `/baikal/novyy-god/` показан тур с заездами с 4 января).
3. Цены на 5 экскурсий (Листвянка, Аршан, Байкальск, теплоход, Иркутск) — сейчас «по запросу».
4. «Философия бани зимой» — на старом сайте была копией летней, программа переписана под зиму, проверить.
5. Летние даты 2027 (сейчас у части туров даты 2026 — они скроются сами после прохождения).
6. Другие регионы: какие из туров Камчатки (5), Владивостока (10), Краснодара (4) действуют и их программы; актуальность алтайских цен. У всех этих страниц на Tilda стоял canonical на btc-tour.com и чужие контакты — на новом сайте они убраны.
7. Актуальность рейсов и цен в таблицах `/baikal/iz-moskvy/` и `/baikal/iz-spb/`.
8. Размер комиссии для агентов (`/agentam/`), направления на `/world/`.
9. Юридический текст политики конфиденциальности.
10. Фото архивом: живые кадры с хивуса, Хобоя, бань, людей в кадре. Старый сайт на Tilda **не отключать**, пока фото не перенесены.
11. Ключи Telegram-бота.

Яндекс.Вебмастер + sitemap, Google Search Console, Яндекс.Бизнес и 2ГИС (телефон и адрес — как на сайте, до символа), просить отзывы. Метрика 97885909 уже в коде (`components/Metrika.tsx`).

Честные сроки: индексация 100 страниц — 2–4 недели; «тур на байкал из москвы», «новый год на байкале 2027», «байкальский лёд тур» — топ-10 через 2–4 месяца; «туры на байкал» (20 000 показов) — борьба на полгода и больше против возраста доменов конкурентов.

## 6. Дизайн

Направление — сам зимний Байкал, а не «шаблон турфирмы»: палитра из фото на главной (глубокая бирюза льда `#1F6C7D` / `#0F3A4A`, снежный фон `#F3F8FA`, единственный тёплый акцент — золото рассвета `#E9B86C` на кнопках бронирования и «мест осталось»). Шрифты Manrope (текст) + Playfair Display (заголовки), оба с кириллицей, подключены локально. Фирменный элемент — линия ледяной трещины (`components/IceLine.tsx`). Туры — строками с ценой и ближайшим заездом справа, а не одинаковыми карточками. Мобильная нижняя панель: Позвонить / Telegram / Подобрать тур.

Для перебора вариантов дизайна: присылать словами или скриншотом — меняются только `globals.css`, `tailwind.config.ts` и `components/`, контент не трогается.
