## Важно: один файл нужно удалить вручную

Архив только добавляет и заменяет файлы, удалять он не умеет. Поэтому после загрузки зайдите в репозиторий, в папку `public/img/tours/`, и удалите файл:

**`teplokhod-8.webp`**

Это тот самый галечный пляж 800×600 — из данных сайта он уже убран, но сам файл останется висеть в репозитории и занимать место.
