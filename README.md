# Правка: ошибки разметки товара в Google Search Console

## Что было

Google прислал две жалобы:
- **критическую** — «отсутствует поле image»: такие страницы не допускаются к показу расширенным сниппетом;
- незначительные — «отсутствует review» и «отсутствует aggregateRating».

Проверка нашла 46 проблемных блоков. На английских страницах туров в разметке не было ни фотографии, ни бренда, ни рейтинга. На русских в поле фотографии стояла общая заглушка вместо кадра тура. Отзыв не выводился нигде — был только сводный рейтинг, а Google просит рядом с ним хотя бы один отзыв.

## Что исправлено

`lib/seo.ts` — в разметку подставляется реальное фото тура: обложка, при её отсутствии первый кадр галереи, и только потом заглушка. Добавлен отзыв из тех, что уже есть в данных сайта.

`app/en/baikal/tury/[slug]/page.tsx` — английская разметка приведена к русской: фото, бренд, рейтинг, отзыв и сводное предложение с обеими границами цены.

Проверено: проблемных блоков не осталось.

## Про остальные пункты письма

`hasMerchantReturnPolicy`, `shippingDetails` и GTIN — это поля интернет-магазина: политика возврата, условия доставки и штрихкод. Для туров они бессмысленны, заполнять их нечем. Google помечает их как незначительные, на показ они не влияют — эти предупреждения останутся, и это нормально.

## Как залить

Два файла по тем же путям, коммит. После пересборки в Search Console нажать «Проверить исправление» по обеим ошибкам.
